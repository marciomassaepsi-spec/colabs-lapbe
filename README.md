# Colabs LAPBE

Formulário para ligantes se candidatarem a fazer posts em colaboração com a LAPBE no Instagram durante as férias. Ao final, o ligante gera um PDF com todas as respostas.

Site estático (HTML, CSS e JS), sem build. O PDF é gerado no navegador com jsPDF; nenhum dado é enviado a servidor.

## Publicar no GitHub Pages

Settings → Pages → Source: Deploy from a branch → escolha a branch e a pasta `/ (root)`.

## Editar

- Temas de interesse: lista de checkboxes em `index.html` (`#temas`).
- Cores: variáveis no topo de `style.css`.
